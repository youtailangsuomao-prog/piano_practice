# ピアノ練習アプリ

電子ピアノ/キーボード(MIDI接続対応)と組み合わせて使う、ブラウザだけで動くピアノ練習アプリです。
MIDIファイルを読み込むと、鍵盤の上に音符が降ってくる画面(Synthesia風)で曲を確認しながら、実際に弾いた音をリアルタイムで判定してくれます。

## できること

- **お手本を聴くモード**: 読み込んだ曲をアプリが自動演奏し、どの鍵盤をどのタイミングで弾くのか確認できます。
- **練習モード**: 電子ピアノをMIDI接続すると、弾いた音を自動で正誤判定(正解=緑、違う音=赤でフラッシュ)。「正しい音を弾くまで待つ」設定をONにすると、次の音を弾くまで曲が先に進まないので、初心者でも自分のペースで練習できます。
- **速度調整**(0.5x〜1.5x)・**片手練習**(右手のみ/左手のみ/両手)・**スコア表示**(正解数・ミス数・正答率)。
- MIDIキーボード未接続でも、画面上の鍵盤をクリックして練習フローを試せます。

## 使い方

1. 依存パッケージをインストール: `npm install`
2. 開発サーバーを起動: `npm run dev`
3. ブラウザ(**Chrome または Edge** 推奨。Web MIDI APIが必要なため Safari は非対応)で開く
4. 「1. 曲を読み込む」から MIDIファイル(`.mid`)を選択、またはサンプル曲を選んで読み込む
5. 「2. 電子ピアノ/キーボードと接続」で MIDI デバイスに接続(USBまたはBluetooth MIDI)
6. 「3. 練習する」でモードや速度を選び、再生

## 楽譜(曲)の準備について

このアプリは **MIDIファイルを読み込んで練習する方式** です。市販の流行曲のMIDIデータそのものは著作権の関係でアプリに同梱していません。以下のような方法でMIDIファイルを用意してインポートしてください。

- 楽譜作成ソフト(MuseScore など)で楽譜を作成・編集し、MIDIとして書き出す
- 自分で購入・作成した楽曲データをMIDI変換する
- 動作確認用に、著作権フリーの童謡「きらきら星」と、オリジナルの指ならし練習曲「ドレミの練習」を同梱しています(`public/songs/`)

将来的に手持ちの紙の楽譜(PDF)をそのまま読み込む光学楽譜認識(OMR)は精度の課題が大きいため今回は採用していません。

## 技術構成

- React + TypeScript + Vite(静的サイトとしてビルド可能。バックエンドサーバーなし)
- [Web MIDI API](https://developer.mozilla.org/ja/docs/Web/API/Web_MIDI_API): 電子ピアノとの接続・入力音の検出
- [@tonejs/midi](https://github.com/Tonejs/Midi): MIDIファイルのパース
- [Tone.js](https://tonejs.github.io/): 「お手本を聴く」モードの音声合成
- 練習エンジン本体(`src/engine/practiceEngine.ts`)は Reactの外側で独自の再生クロック(requestAnimationFrame)を持ち、`useSyncExternalStore` でReactに必要な部分だけ通知する設計にしています
